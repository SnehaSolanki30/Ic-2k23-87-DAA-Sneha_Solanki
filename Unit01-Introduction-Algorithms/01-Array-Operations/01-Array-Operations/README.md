# Array Operations

## Problem Statement
Read an array, display its elements, calculate their sum, and search for a given value.

## Approach
Implement the algorithm using simple Java statements, loops, conditions and methods.

## Time and Space Complexity
Time: O(n) for display, sum and search. Extra space: O(n) for the array.

## How to Run
Compile: `javac ArrayOperations.java`
Run: `java ArrayOperations`

## Learning Outcome
Understand the algorithm, its steps, and its basic complexity.
