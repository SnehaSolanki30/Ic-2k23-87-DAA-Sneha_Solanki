# Iterative Binary Search

## Problem Statement
Search for a value in a sorted array by repeatedly dividing the search range into two halves.

## Approach
Implement the algorithm using simple Java statements, loops, conditions and methods.

## Time and Space Complexity
Time: O(log n) for search. Extra space: O(1), excluding sorting.

## How to Run
Compile: `javac IterativeBinarySearch.java`
Run: `java IterativeBinarySearch`

## Learning Outcome
Understand the algorithm, its steps, and its basic complexity.
