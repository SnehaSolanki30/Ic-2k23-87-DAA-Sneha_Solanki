# Recursive Binary Search

## Problem Statement
Search for a value in a sorted array by calling the same method on a smaller half.

## Approach
Implement the algorithm using simple Java statements, loops, conditions and methods.

## Time and Space Complexity
Time: O(log n). Extra space: O(log n) due to recursive calls.

## How to Run
Compile: `javac RecursiveBinarySearch.java`
Run: `java RecursiveBinarySearch`

## Learning Outcome
Understand the algorithm, its steps, and its basic complexity.
