## About This Repository

This repository contains Java implementations of algorithms
covered in the Design and Analysis of Algorithms Laboratory.

It includes source codes, algorithm explanations, pseudocode,
flowcharts, complexity analysis, sample outputs and performance
experiments.

## Units

1. Introduction to Algorithms
2. Divide and Conquer
3. Greedy Method
4. Dynamic Programming
5. Traversal and Search
6. Backtracking
7. NP-Hard and NP-Complete
