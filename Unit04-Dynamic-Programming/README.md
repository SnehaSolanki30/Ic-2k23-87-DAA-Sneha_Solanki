# Unit 04 – Dynamic Programming

## Topics Covered

1. Fibonacci Series using Recursion
2. Fibonacci Series using Memoization
3. 0/1 Knapsack using Dynamic Programming
4. Multistage Graph
5. Floyd-Warshall Algorithm
6. Single Source Shortest Path
7. Travelling Salesman Problem using Dynamic Programming

## Performance Analysis

- Compare Recursive and Memoized Fibonacci.
- Compare Greedy and Dynamic Programming approaches for suitable optimization problems.
- Analyze time and space complexity.
- Study algorithm performance.

## Application

Route Optimization System

## Programming Language

Java

## Objective

To understand Dynamic Programming and solve complex problems by dividing them into smaller overlapping subproblems.
