# Unit 07 – NP-Hard and NP-Complete

## Topics Covered

1. Introduction to NP-Hard and NP-Complete Problems
2. Exhaustive Search Demonstration
3. 0/1 Knapsack using Branch and Bound
4. Travelling Salesman Problem using Branch and Bound
5. Comparison of 0/1 Knapsack using Dynamic Programming and Branch and Bound
6. Comparison of TSP using Dynamic Programming and Branch and Bound

## Performance Analysis

- Compare input size and execution time.
- Analyze the number of explored nodes.
- Compare memory usage.
- Study solution quality.
- Analyze algorithm scalability.

## Application

Optimization Algorithm Comparison System

## Programming Language

Java

## Objective

To understand NP-Hard and NP-Complete problems and compare different techniques used to solve optimization problems.
