# Quick Sort

## Aim
To sort an array using the Quick Sort algorithm.

## Algorithm
1. Select an element as pivot.
2. Place smaller elements on the left side.
3. Place greater elements on the right side.
4. Apply Quick Sort to both partitions.
5. Display the sorted array.

## Time Complexity
- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n²)

## Space Complexity
O(log n) average recursion stack.

## Sample Input
9 4 7 3 10 5

## Sample Output
[3, 4, 5, 7, 9, 10]

## Conclusion
Quick Sort uses a pivot element to divide an array into smaller parts.
