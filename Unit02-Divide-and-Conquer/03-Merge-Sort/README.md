# Merge Sort

## Aim
To sort an array using the Merge Sort algorithm.

## Algorithm
1. Divide the array into two halves.
2. Apply Merge Sort to both halves.
3. Merge both sorted halves.
4. Repeat until the complete array is sorted.

## Time Complexity
- Best Case: O(n log n)
- Average Case: O(n log n)
- Worst Case: O(n log n)

## Space Complexity
O(n)

## Sample Input
8 3 5 1 9 2

## Sample Output
[1, 2, 3, 5, 8, 9]

## Conclusion
Merge Sort divides the array into smaller parts and merges them in sorted order.
