# Maximum and Minimum using Divide and Conquer

## Aim
To find the maximum and minimum elements of an array.

## Algorithm
1. Divide the array into two halves.
2. Find minimum and maximum in the left half.
3. Find minimum and maximum in the right half.
4. Compare both results.
5. Display the final minimum and maximum.

## Time Complexity
O(n)

## Space Complexity
O(log n) recursion stack.

## Sample Input
5
10 5 20 3 15

## Sample Output
Minimum = 3
Maximum = 20

## Conclusion
Divide and Conquer helps find minimum and maximum by dividing the array into smaller parts.
